# lan-share

Передача файлов и папок по локальной сети без сервера, облака и регистрации.
Только стандартная библиотека Python 3.8+, зависимостей нет.

- Поиск получателя по имени в сети (`--name Masha-PC`) или по адресу (`--to host:port`)
- Код сопряжения вида `42-apple-river`, из него выводится общий ключ (SPAKE2)
- Шифрование и проверка целостности всего трафика
- Папки целиком, контрольная сумма SHA-256 каждого файла
- Подтверждение на стороне получателя («принять 3 файла от Маши?»)
- Докачка после обрыва, пропуск уже имеющихся файлов
- Отправка нескольким получателям одновременно
- Прогресс-бар и скорость

> ⚠️ Шифрование собрано из стандартных примитивов Python и не проходило аудит.
> Подходит для домашней и рабочей сети. Для действительно чувствительных данных
> используйте проверенные инструменты (magic-wormhole, age, croc).

## Установка
```
pip install .        # появится команда lanshare
# или без установки:
python -m lanshare --help
```

## Использование

**Получатель:**
```
lanshare receive --out ~/Downloads --name Masha-PC
```
Напечатает код сопряжения, например `96-timber-quartz`, и будет ждать.

**Отправитель:**
```
lanshare scan                                    # кто есть в сети
lanshare send --name Masha-PC photos/ report.pdf # найти по имени
lanshare send --to 192.168.1.5:9000 file.zip     # или по адресу
```
Код сопряжения спросит интерактивно (или `--code 96-timber-quartz`).
Получатель увидит вопрос и ответит `y`.

Несколько получателей сразу:
```
lanshare send --name Masha-PC --name Petya-Laptop video.mp4
```

Опции `receive`: `--port`, `--out`, `--name`, `--code`, `--yes` (без вопроса),
`--once` (выйти после одной передачи), `--no-discovery`.

## Тесты
```
python -m unittest discover -v
```
48 тестов: криптография (подмена, повтор, перестановка кадров), передача файлов
(пустые, нечётные размеры, 20 МБ, юникод, папки), неверный код, отказ, докачка,
конфликты имён, атаки через манифест (выход за пределы папки, ложные размеры),
обрыв соединения, параллельные получатели, обнаружение.

## Известные ограничения
- Обнаружение: собственный UDP-протокол, не mDNS. Работает в одной подсети;
  на машинах с несколькими интерфейсами (VPN, Docker) multicast может уходить
  не в ту сеть, тогда используйте `--to host:port`. Файрвол должен пропускать
  TCP-порт получателя (9000) и UDP 50505.
- Скорость около 60 МБ/с на ядро из-за шифрования на чистом Python.
- Пустые папки и симлинки не передаются.
- Пока нет веб-интерфейса для телефона.
